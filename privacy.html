개인정보처리방침

Hermes Personal Automation · 최종 개정 2026년 11월 20일

본 개인정보처리방침은 개인용 자동화 애플리케이션 Hermes Personal Automation(이하 "본 앱")이 Google 계정 데이터에 어떻게 접근하고 사용하는지 설명합니다. 본 앱은 단일 사용자(계정 소유자 본인)의 개인 기기에서만 실행되는 개인용 도구이며, 외부 사용자에게 제공되는 서비스가 아닙니다.

1. 접근하는 Google 데이터

사용자가 직접 동의한 범위에 한해 다음 데이터에 접근합니다.

서비스접근 범위사용 목적
Gmail읽기, 보내기, 라벨 수정알림 메일 발송, 메일 검색 및 정리
Google Calendar일정 조회 및 생성일정 확인과 개인 일정 등록
Google Drive파일 조회, 업로드, 다운로드개인 문서 보관 및 백업
Google Sheets시트 조회 및 편집개인 기록 관리
Google Docs문서 조회 및 생성개인 문서 작성
Google Contacts읽기 전용연락처 확인

2. 데이터의 이용

접근한 데이터는 오직 계정 소유자 본인의 요청을 수행하는 데에만 사용됩니다. 광고, 프로파일링, 행동 분석, 모델 학습, 제3자 제공 등 다른 목적으로는 사용하지 않습니다.

3. 데이터의 저장과 전송

  • OAuth 접근 토큰과 갱신 토큰은 사용자의 개인 기기 내 로컬 저장소 (~/.hermes/google_token.json)에만 보관됩니다.
  • 본 앱은 자체 서버를 운영하지 않으며, 계정 데이터를 별도 서버에 저장하거나 전송하지 않습니다.
  • 데이터는 Google API와 사용자 기기 사이에서만 직접 주고받습니다.

4. 제3자 제공

접근한 Google 데이터를 판매, 대여, 공유, 이전하지 않습니다. 법령상 요구되는 경우를 제외하고 어떤 제3자에게도 제공하지 않습니다.

5. 보관 기간과 삭제

  • 로컬에 저장된 토큰은 사용자가 언제든지 파일을 삭제하거나 --revoke 명령으로 제거할 수 있습니다.
  • 앱의 접근 권한은 Google 계정 권한 페이지에서 언제든지 직접 해제할 수 있습니다. 권한을 해제하면 본 앱은 더 이상 해당 데이터에 접근할 수 없습니다.
  • 본 앱이 별도로 보관하는 계정 데이터는 없으므로, 권한 해제 외에 별도의 삭제 절차가 필요하지 않습니다.

6. Google API 서비스 사용자 데이터 정책 준수

본 앱은 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy)을 준수하며, 제한적 사용(Limited Use) 요구사항을 포함합니다. 본 앱은 Google 사용자 데이터를 다음과 같이 취급합니다.

  • 사용자에게 명시적으로 공개된 기능을 제공하기 위해서만 사용합니다.
  • 제3자에게 이전하지 않습니다. 단, 법령 준수, 보안 조치, 정책 위반 대응에 필요한 경우는 예외입니다.
  • 광고 목적으로 사용하지 않습니다.
  • 사람이 열람하지 않는 한, 사용자 데이터를 열람할 수 있는 다른 사람에게 제공하지 않습니다.

Privacy Policy (English)

Hermes Personal Automation is a single-user, personally operated automation tool that runs only on the account owner's own device. It is not offered as a service to other users.

Data accessed. With the owner's explicit consent: Gmail (read, send, modify labels), Google Calendar (read, create), Google Drive (read, upload, download), Google Sheets and Google Docs (read, edit), and Google Contacts (read-only).

Use. Data is used solely to perform the owner's own requested actions — for example sending notification emails, checking schedules, and storing personal documents. It is never used for advertising, profiling, analytics, or model training.

Storage. OAuth tokens are stored only in a local file on the owner's device (~/.hermes/google_token.json). The app operates no server and does not transmit account data to any third party. Data moves only between the Google APIs and the owner's device.

Sharing. No Google user data is sold, rented, shared, or transferred to third parties, except where required by law.

Retention and deletion. Tokens can be deleted at any time by removing the local file or running the revoke command. Access can be withdrawn at any time at myaccount.google.com/permissions. No account data is retained elsewhere.

Limited Use. This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
